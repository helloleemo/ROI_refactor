# QA 測試計畫 — EnergyAI ROI Refactor

> 版本:v1.0|測試型態:手動功能測試(Checklist)
> 執行方式:依序執行各測試案例,記錄「實際結果」與「Pass / Fail」,失敗案例依文末格式回報。

---

## 1. 測試環境準備

| 項目 | 內容 |
| --- | --- |
| 啟動指令 | `npm install` → `npm run dev` |
| 測試網址 | `http://localhost:5173/{projectId}/...`(需帶有效 projectId) |
| 測試瀏覽器 | Chrome / Edge 最新版(必要時加測 Firefox) |
| 測試資料 | 後端 API 需可連線;另需準備一份翻譯匯入用 CSV/檔案、一份上傳測試用 CSV |
| 視窗尺寸 | 1920×1080 為主,另抽測 1366×768 |

## 10. 回歸測試原則

- 每次修改後至少重跑:被改動頁面全部案例 + G-01~G-10 全域案例。
- 發版前執行完整 checklist 一輪(六個語言至少抽測 zh-TW + en-US)。

```
【標題】[頁面] 簡述問題
【環境】瀏覽器版本 / 語言 / 主題(Light/Dark)

【預期結果】
```
